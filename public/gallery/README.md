# Gallery photos

The site reads `/public/gallery/<slug>.jpg` (lowercase `.jpg`, ~1600px wide, under 500 KB).
Browsers cannot display `.HEIC`, and Vercel's filesystem is case-sensitive (`.JPG` != `.jpg`).

| File name                 | Shows                                           |
|---------------------------|-------------------------------------------------|
| `mpp-manifesto.jpg`       | MPP election manifesto poster                   |
| `breakfast-boost.jpg`     | MPP Care Breakfast Boost at Dataran Lestari     |
| `warna-warni-warisan.jpg` | Warna-Warni Warisan Terengganu banner           |
| `masmed-seminar.jpg`      | MASMED Eastern Region seminar                   |
| `welfare-walk.jpg`        | Non-resident welfare visit (Lawatan Muhibah)    |

Other files in this folder are unused source originals.
